## Requires Schedule I Alternate
Opt-in to the Alternate branch by doing the following:
- Right click on the game in the steam
- Click "Properties"
- Click "Betas"
- Select "alternate" from the dropdown
  - Optionally, you can select "alternate-beta" if you still want the beta features from Tyler. Note: Beta versions may be less stable and we take no responsibility for corrupt saves

*Always backup your saves*

## Planned Features & Improvements
I plan to eventually add more configuration and to move the display to the phone. Feel free to contribute by making pull requests to the [launderingstatus branch](https://github.com/YahYah-Games/Schedule-I-Mods/tree/launderingstatus/LaunderingStatus).

## Dependencies
These are mods that LaunderStatus depends on. Thunderstore *should* auto-install these if you're using the Mod Manager, but if you're installing mods manually, be sure to install these as well:
- MelonLoader v0.7.0 (Required for most S1 mods so you might have this installed already. It's recommended that you use the installer)
- S1API v1.6.2
